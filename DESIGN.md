# 🎨 Froopyland game design (js13k 2026)

**Genre:** narrative adventure — 7 trials, one per rainbow color: puzzle → action shooter → memory → collection → tracing → boss duel → connect-the-pipes
**Motivation:** S3E9 *"The ABC's of Beth"* — Tommy's dad is sentenced to death, *"I'd rather slaughter this whole place than apologize"*, the finger, the clone
**Competition theme:** Unicorns and Rainbows

## Story & phases

### Start screen
- Dark background with a faint rainbow arc, **FROOPYLAND** title and a handwritten **RICK AND BETH** subtitle (in the style of the show's logo), a green **▶ PLAY** button
- All four characters lined up below: Rick, Beth, a unicorn, Tommy — the same procedural canvas style as in-game
- **Debug level buttons** (GAR · NEST · GATE · CELLS · TRACE · TOMMY · DNA) exist in the dev build only and are **stripped from the submission package** by the build script

### Trial 1 — 🔴 GAR: Rick's garage (cable puzzle)
- Fullscreen dark screen, no scenery — just the puzzle and dialogs
- 4 pipes × 7 segments; tapping a segment rotates it **and its right neighbour** (plus/plus), 0° = connected
- Scramble is generated by simulated clicks from the solved state → always solvable
- Exposition: Beth about the execution → Rick about the fried projector → the 13KB meta-joke; after Beth says they must find Tommy, Rick answers they must grind through **"SEVEN trials — one per rainbow color"** — theme reinforcement

### Trial 2 — 🟠 NEST: the nest (action defense)
- Froopyland welcome dialogs ("child-proofed… NOTHING can go wrong") → a giant winged pony appears and carries Rick to the nest (animated flight, Rick *inside* the nest at (800, 222))
- Beth at the nest rim: tap anywhere to shoot; hatchlings fly in from both sides toward Rick
- **Rick has 1 HP: a single bite = the whole wave restarts** (restart is announced as a real dialog, tap to continue)
- 10 kills → round-two dialogs + faster spawns; 20 kills → Rick becomes pack leader, victory

### Trial 3 — 🟡 GATE: memory gate (Simon says)
- Fullscreen light board, three lamps in the center; **five sequences in a row**
- Demonstration phase (each lamp flashes with its tone, 0.55 s per step), then input phase
- Any mistake: red X on all lamps, **all five rounds reset**, round 1 shown again
- Honest **1-second pause** between rounds; `ROUND r/5` indicator above the lamps

### Trial 4 — 🟢 CELLS: memory cells (collection run)
- Meadow, five floors, rainbow ladders between them; five memory cells scattered around
- Beth takes **one cell at a time** and must walk it to **Rick, who stands at the matrix in the bottom-right** — no auto-walk, the player drives everything (ladder climbing included)
- HUD: `CELLS n/5 → RICK` while carrying
- Touching a chasing froupie **restarts the whole level** (cells and Beth's position reset)

### Trial 5 — 🔵 TRACE: the chalk lock (tracing)
- Fullscreen light board like GATE — only the dot zigzag and dialogs; 36 dots (4 columns × 9 rows on phones, more columns on desktop), procedurally fitted to the window
- Hold and drag through the dots in order; releasing off-track / missing resets the trace; the line is rainbow-colored
- Win → *"Chalk beats chalk, kiddo."* → trial 6

### Trial 6 — 🟣 TOMMY: knife duel (boss fight)
- Tommy patrols and throws knives along ballistic arcs; a knife hit restarts the duel
- **Pink arrow on a pedestal top-left** (floor 4): Beth takes it → tap Beth to enter aim mode → tap Tommy to fire (the arrow flies like his knives, then **respawns at the pedestal**)
- **3 hits → Tommy stops** ("FINE! I'll stand STILL!") → walk up to him → finish → kill scene dialogs
- No Rick and no grey portal on the map — clean arena; HUD shows `DODGE · GET ARROW ↑` / `TAP BETH — AIM!` / `TAP TOMMY — FIRE!`

### Trial 7 — 🌈 DNA: the clone sequencer (connect the pipes)
- Fullscreen dark screen, **6 columns × 12 rows** portrait grid so every phone fits (cell ≈ 38 px on a 360×740 screen)
- Tiles: straight, corner, tee; tap rotates 90°; connect **IN (left edge, top) to OUT (right edge, bottom)**
- Generator draws a real top-left→bottom-right path (random walk of the path column per row), fills gaps with random tiles, then scrambles by random rotations — solvable by construction
- On wide screens the grid is flanked by decorations: the **clone capsule** (left) and the **finger sequencer** (right), with dashed connector lines; they auto-hide when there is no room (phones)
- Win → *"Wubba lubba dub dub! …we are amoral geniuses"* → `TOMMY LIVES. YOU MONSTER.`

## Controls

Mouse / touch **only** (keyboard handlers were removed in the mobile-first pass).

| Input | Action |
|---|---|
| Tap | rotate a cable / lamp / shot; tap the dialog panel to advance; PLAY |
| Tap a spot | Beth walks there (routes through ladders: walk → climb → walk) |
| Hold & drag | joystick (NEST rim walking, CELLS, TOMMY); TRACE dot tracing |
| Tap Beth | enter aim mode (TOMMY trial only) |

## Dialogs

- Bottom panel always present; height scales with the screen (up to 280 px) so long lines fit on phones; font auto-shrinks and word-wraps inside the real available area
- Speaker portrait on the left; the mouth of whoever talks is animated
- A queue of lines per phase + event reactions; tap advances (0.4 s debounce)
- **Text is deduplicated into shared phrase variables** (`bq` = `*burp* `, `wu` = `Wubba lubba dub dub!`, `fl` = `flip it AND its neighbour`, `cd` = `chalk door`, `so` = `say sorry`, `wl` = `Walk it off. WALK IT OFF.`, `ht` = `hatchlings`, `zp` = `zap them`) — reused across dialog arrays to save bytes
- In English, in the show's spirit; the 13KB limit is a running meta-joke

## Sound (WebAudio, synthesized)

Steps, pickup chime, neigh, hit, puzzle click, "OK" jingle, tone steps for GATE lamps, knife throw, zap, Rick's burp. Initialized on the first user gesture (browser autoplay policy). Zero audio files.

## Size reduction — how we fit into 13 KB

The final package is **13,277 bytes of 13,312** (35 bytes to spare). Raw sizes: `game.js` ≈ 38.8 KB, `index.html` ≈ 0.5 KB.

### Pipeline (the only tools used)

1. **Strip debug level buttons** — a small Node script removes the `DBG` table, the menu-click branch and the drawing loop (saves ~175 B of zip in the final build)
2. **Minify:** `npx terser game.js -c passes=4,unsafe,toplevel -m toplevel -o out.js`
   - `passes=4` — four compression passes
   - `unsafe` — aggressive but safe-in-practice transforms
   - `-m toplevel` — rename top-level identifiers (the game is fully self-contained, nothing external references its globals)
   - output is syntax-checked with `node --check` and smoke-tested in Node with stubbed canvas/AudioContext (boot → PLAY → dialogs → a real click produces a sound)
3. **Package:** `zip -q -9 -X index.html game.js` (max DEFLATE, no extra fields)
   - `advzip`/zopfli recompression was tried but is not installable here — plain `zip -9` already fits

### Measured numbers

| Variant | raw zip | terser (no toplevel) | terser + toplevel mangle |
|---|---|---|---|
| With debug buttons | 14,675 B | 13,941 B ❌ | 13,452 B ❌ (+140) |
| **Without debug buttons** | 14,483 B | 13,766 B ❌ | **13,277 B ✅** |

### What bought the bytes

- **Phrase variables in dialogs** — repeating lines (`*burp* `, `Wubba lubba dub dub!`…) live in 1-letter consts (~300–500 B saved before minification)
- **Single-file procedural everything** — zero images, fonts or audio files; characters, backgrounds and sounds are drawn/synthesized in code
- **Keyboard removal** — one input path (pointer) instead of two
- **Debug buttons stripped** in the submission build only (they stay in the repo for testing)
- **Toplevel mangling** — the single biggest terser win here (~660 B of zip vs plain minify)
- Shared drawing helpers (one `beth()`/`rick()`/`uni()`/`tommy()` per character), one `snd()` synth for all effects, and formulas reused between draw & hit-testing so both always agree

## Limits & tech

- Canvas render + WebAudio, everything procedural, zero asset files
- Hosted on GitHub Pages; the repository keeps the readable source (js13kGames rule: readable repo + minified playable zip)
- Must run in latest Chrome and Firefox with **no console errors**
